## Документация (wiki-стиль)

Этот каталог можно использовать как "мини‑wiki" проекта.  
Основные разделы:

- [`overview.md`](overview.md) — общее описание проекта и основных сценариев.
- [`backend-architecture.md`](backend-architecture.md) — архитектура backend, слои, основные модули.
- [`monitoring-and-load-testing.md`](monitoring-and-load-testing.md) — метрики, Grafana/Prometheus и нагрузочные тесты.
- [`testing.md`](testing.md) — обзор структуры тестов и как их запускать.

Расширяй разделы по мере развития проекта (новые фичи, решения, договорённости по API и т.п.).
