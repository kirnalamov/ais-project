## Архитектура backend

Backend написан на **FastAPI** и организован по слоям:

- `app/main.py` — точка входа приложения:
  - инициализация БД и демо‑данных;
  - подключение роутеров;
  - включение CORS и метрик Prometheus.
- `app/db.py` — настройка SQLAlchemy:
  - `engine`, `SessionLocal`, `Base`;
  - `init_db()` — создание таблиц.
- `app/models.py` — ORM‑модели (пользователи, проекты, задачи, зависимости, сообщения, лог активности и т.д.).
- `app/schemas.py` — Pydantic‑схемы запросов/ответов.
- `app/routers/*` — эндпоинты:
  - `auth.py` — логин, регистрация, текущий пользователь;
  - `users.py` — CRUD пользователей, поиск, статистика;
  - `projects.py` — проекты и участники;
  - `tasks.py` — задачи, зависимости, чат;
  - `analysis.py` — построение графа проекта и критического пути;
  - `events.py` — уведомления/события.
- `app/services/*` — сервисная логика (демо‑данные, планирование и т.д.).

### Поток запроса

1. Клиент обращается к API (`/auth`, `/projects`, `/tasks` и т.д.).
2. FastAPI резолвит зависимости:
   - `get_db()` — создаёт сессию БД;
   - `get_current_user()` / `require_roles()` — авторизация и роли.
3. Роутер вызывает бизнес‑логику (через модели и сервисы).
4. Ответ сериализуется через Pydantic‑схемы.
