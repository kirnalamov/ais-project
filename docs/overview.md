## Обзор проекта

**AIS Corporate Task Planner** — веб‑приложение для управления проектами и задачами с поддержкой:

- декомпозиции проектов на задачи;
- зависимостей задач (DAG) и расчёта критического пути;
- ролей пользователей (admin / manager / executor);
- визуализации графа и диаграммы Ганта;
- встроенного чата по задачам.

### Основные компоненты

- **Backend**: FastAPI + SQLAlchemy + PostgreSQL (или SQLite локально).
- **Frontend**: React + TypeScript (Vite).
- **Инфраструктура**: Docker / docker-compose, Prometheus, Grafana.

### Типичный сценарий работы

1. Админ/менеджер создаёт проект.
2. Менеджер набирает участников проекта.
3. Создаются задачи, настраиваются зависимости и исполнители.
4. Исполнители обновляют статусы задач, ведут переписку в чате.
5. Через граф/Гант анализируется критический путь и загрузка.
